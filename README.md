
# ⚪️ o-omok (오! 오목!) 2019
> **C++ 순수 콘솔 환경에서 구현한 휴리스틱 AI 기반 오목 게임**

별도의 그래픽 라이브러리 없이 C++만을 활용하여 19x19 바둑판 위에서 작동하는 오목 게임을 구현했습니다. 트리 탐색 기반의 무거운 알고리즘 대신, 특정 패턴을 검사하는 **휴리스틱 AI**를 설계하여 가볍운 대국이 가능하도록 개발했습니다.

## Key Features
* **Heuristic-based AI**: 19x19 바둑판의 모든 좌표에 대해 주변 돌의 몇가지 사전 정의된 배치를 검사해 작동하는 커널 기반 검사 알고리즘을 적용했습니다.
* **Console UI**: 콘솔 환경에서도 방향키를 이용한 직관적인 게임 화면과 메뉴 인터페이스를 구축했습니다. 아스키 아트를 통해 디자인 요소를 추가했습니다.
* **Difficulty Selection**: 플레이어의 선/후공 선택 기능을 통해 간접적인 난이도 조절 기능을 제공합니다.

---

## Tech Stack
- **Language**: C++
- **Environment**: Windows Console (ASCII Art 기반 인터페이스)
- **Algorithm**: Heuristic Pattern Matching

---

## Technical Challenge: AI Algorithm
일반적인 오목 AI는 수많은 경우의 수를 계산하는 트리 탐색(Minimax 등)을 사용하지만, 본 프로젝트에서는 다음과 같은 **휴리스틱 방식**을 채택했습니다.

1. **패턴 가중치 설정**: '연속된 3알', '열린 4알' 등 승리에 직결되는 패턴을 우선 검사합니다.
2. **결과**: 트리 탐색 방식보다 가볍게 단순하게 즐길수 있는 AI에이전트를 구축했습니다.

## How to Play
1. **게임 실행**: 프로그램 실행 후 시작 화면에서 'Y'를 입력하여 대국을 시작합니다.
2. **난이도 설정**: 방향키를 이용해 공격 순서(선공/후공)를 결정합니다.
   - **선공**: 플레이어가 먼저 시작 (비교적 쉬움)
   - **후공**: AI가 먼저 시작 (어려움)
3. **조작 방법**: 방향키로 포인터를 움직여 바둑판 돌을 놓습니다.
4. **승리 조건**: 가로, 세로, 대각선 중 먼저 5알을 잇는 쪽이 승리하며 결과 화면이 출력됩니다.
